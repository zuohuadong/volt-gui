# 桌面端真机验收清单

依据 CNB `anyong-agent` 的 `00fbdf723` 适配本仓库。
本清单是待执行的验收标准，不是通过记录；当前外部验收状态仍为 `PARTIAL`。
自动测试、源码构建、macOS staging 与 Windows x64 真机验收是不同证据。

## 执行前

- 使用同一候选提交的 Windows x64 安装器和 ZIP，记录 SHA256、PE 架构、
  Authenticode `NotSigned` 与 packaged DSH smoke 结果。未签名包只用于评审。
- 使用独立的测试工作区和 DSH 数据目录，不破坏真实历史、凭据或共享目录。
  迁移测试先备份，故障注入只对测试副本执行。
- 准备经授权的测试模型、BrowserSkill、SMB 与企业服务账号。
  没有凭据的项目记 `BLOCKED`，不能以模拟结果记 `PASS`。

## 终端

1. 会话中通过快捷面板打开终端，输入 `echo hi`。通过：出现提示符及回显。
2. 调整窗口大小。通过：列宽正确更新，输出可读，不与其他控件重叠。
3. 切换会话、关闭面板、重载界面和退出应用后分别检查。
   通过：不串入旧会话输出，已释放终端无遗留 shell 或子进程。
4. 粘贴超过官方单次字节上限的文本，包括多字节中文与 JSON 转义字符。
   通过：超限有明确未发送提示，不按字符数误判，不截断后偷偷执行。
5. 连续输入与调整尺寸。通过：ACK 流控不会丢序或耗尽 inbox；
   缓冲满时提示背压，断线后的输入不自动重放。
6. 关闭失败后重试。通过：保留可重试的终端身份，不误关新终端。
7. 超过官方空闲回收时间保持面板打开。通过：`terminal/retain` 有效，
   无意外回收。终端使用专用 IPC 与官方流，不调用不存在的 `terminal/readScreen`。

## 团队、队列与反馈

1. 开启团队模式，让 Lead 创建不同状态及依赖的任务。
   通过：状态分组、可认领标记正确；关闭模式不清空官方任务。
2. 长任务运行时提交新消息。通过：进入官方队列，输入框清空，
   插队、取消及纯文本编辑有效；带附件项不会伪造可编辑内容。
3. 重连或重启后读取同一会话。通过：队列与官方状态一致，无本地重复条目。
4. 对有官方消息 ID 的回复评价并撤销，再模拟并发修改。
   通过：评价正确切换；冲突采用官方当前版本，不无限重试。

## 计划、变更与自动化

1. 通过 `/plan` 生成并批准计划。通过：计划正文正确，批准状态更新，
   规划横幅消失。
2. 在测试工作区修改文件。通过：变更卡片与官方 diff 一致；
   Host 重启导致摘要失效时隐藏该卡片，不反复报错。
3. 创建、查看及终止后台任务。通过：输出尾部、状态正确，
   结束后不持续轮询，`stopping` 不重复展示终止操作。
4. 管理页运行定时任务及修改受支持字段。通过：每个结果单独反馈，
   冲突、未找到、正在执行和参数错误不混作成功。
   不要求本地未暴露的 catalog/history/deleteInactive 等独立 RPC。

## 插件、技能与凭据

1. 对有官方 `patchId` 的插件启停。通过：区分 applied、restart-required、
   overridden、failed、cancelled；无可写 ID 的插件保持只读。
2. 在测试输入中使用虚构的疑似密钥串。通过：出现泄漏风险提示，
   不改写原文；不使用或截图真实密钥。
3. 安装、更新、移除经授权的测试技能。通过：列表与实际安装一致；
   失败保留原版本；恶意路径、symlink 和跨源 token 转发被拒绝。
4. 导入导出测试 AgentConfig。通过：预览、确认与取消有效，
   未确认不写入，失败不泄露凭据或破坏已有配置。

## 升级、目录与数据

1. 使用含历史会话的 rc.1 测试数据启动当前 rc.3。
   通过：profile 依赖闭包一致升级，历史可读取，备份保留。
2. 对迁移注入失败或制造目标备份冲突。
   通过：保留原包与 manifest 或明确阻止启动，显示可定位原因；
   不覆盖已有备份。不要假设损坏的用户 YAML 会自动修复。
3. 打开目录选择器、列目录并创建测试目录。
   通过：官方 browse backend/surface 配对，原生文件夹选择仍可用。
4. 永久删除会话和检查自动更新保持不支持状态。
   通过：UI 不伪装为成功，不请求猜测的官方端点。

## Windows 与真实集成

1. 启动随包 PowerShell 7.4.22，再启动嵌套 shell。
   通过：不因 CET 或嵌套进程崩溃。7.7.0 仅在独立测试包通过同一验收后才能升级，
   不放宽现有 .NET 8 / LTS 门禁。
2. 用测试账号访问 SMB，覆盖连接失败、重连及取消。
   通过：路径与权限正确，不泄漏凭据，失败不报告成功。
3. 调用真实模型、BrowserSkill 和企业连接器。
   通过：真实结果可核对，授权和网络策略有效；取消、断网及凭据错误有明确反馈。
4. Office 渲染分别测试有引擎和缺少引擎场景。
   通过：前者产生可验证文件，后者说明缺少引擎，不伪造结果。
