# 表格分析

加载 office-xlsx。默认保留原始文件，分析和清洗结果写到新文件；先确认工作表、表头、数据范围、单位、日期格式及指标口径。

## 大文件必须先选路径

- 先用 `sheet_profile` 看工作表、表头、列类型、空值和规模，不要把整张表读进上下文。
- 需要具体单元格时用 `sheet_query` 指定 `sheet` 和 `A1:H50` 之类的范围；`document_extract_text` 读表格同样要带 `range` 或 `maxLines`。
- 汇总、对账、去重、分组一律用 `sheet_aggregate` 的只读 SQL（表名固定为 `data`），只把结果行回传。
- 引擎报“超过 OfficeCLI 引擎上限”时，不要重试整表读取：改为按工作表/范围拆分，或直接用 `sheet_aggregate`。
- 百万行级文件首次聚合需要十秒级（2000 万单元格约 10s）建立快照，之后命中快照只要零点几秒；不要把超时当成数据为空。
- 同一文件同一工作表的重复查询会直接读快照，优先复用而不是换一个新的范围反复重算。
- 若工具直接拒绝并提示“超过单次转换预算”，不要重试或改用别的工具反复读取：按提示改用 `sheet_aggregate`、转 CSV，或让用户拆分工作表。

优先使用内置 Python：PowerShell 中可使用 $env:ANYONG_PYTHON_COMMAND 指定的解释器；只有实际配置存在时才使用。不要猜测系统 Python 或自动联网安装库。执行真实计算，记录输入范围、过滤条件、缺失值和去重规则，标识排除记录及原因。

将编号、邮编和长整数作为字符串处理；不要丢失前导零。区分空值、零、未知和错误值。跨表合并先检查键是否唯一，报告未匹配行和重复展开。财务或统计指标不能口算。

结果同时提供计算口径、来源、关键校验数及限制。Excel 交付前重新读取，核对行数、总计、公式和格式；公式写入不代表缓存值已经重新计算。含外部文本的单元格按文字写入，避免意外形成公式。
