# 周报汇总

确定报告起止日期和受众，按用户指定的记录或已授权数据来源整理。区分已经完成、进行中、受阻和计划事项；去重时保留证据，不把计划写成成果。

建议结构为本期成果、关键指标、风险与依赖、下期计划。数字由执行工具计算并说明口径；没有数据时不虚构增长率或完成率。标明未覆盖的来源和时间段。

提交前逐项检查成果依据、负责人和时间范围。定时生成必须使用已经接通的官方调度服务，并明确频率、时区和范围；未接通时只生成当前报告，不承诺未来执行。对外发送、群发和知识库上传须单独获得授权。
